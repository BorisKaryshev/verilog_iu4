# Зависимости
Для сборки требуются:
- verilator
- cmake
- make
- C++ Compiler (with C++20)

На Ubuntu установить зависимости можно скриптом:
```
./scripts/setup.sh
```

# Сборка
Собрать любое из заданий можно на Unix-подобной системе следующей командой:
```
cd <task_path>
make
```

Для автоматической очистики можно использовать следующий скрипт:
```
./scripts/cleanup.sh
```
Очистка удаляет артефакты сборки, скомпилированные бинари и vcd файлы.
